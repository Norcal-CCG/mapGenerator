Colors and icons are assigned automatically. Click a color swatch or an icon to change it. Your own icons can be SVG or PNG; only the shape is used (PNGs need a transparent background), so they match the built-in set.

Fonts

For any other font, pick "Other Google Font…", find one at fonts.google.com, and type its name exactly as shown there (capitals count). Web fonts download from Google when the map opens; the others use fonts already on the viewer's computer.
